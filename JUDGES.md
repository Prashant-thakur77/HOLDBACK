## What is real and what is not

| Part                                        | Status                                                                                                                  |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Program                                     | Deployed on devnet, upgrade authority held by the deployer (shown by `make verify`); unaudited                          |
| Risk agent, website, Blink, Supabase mirror | Live, connected to devnet                                                                                               |
| Evidence collectors                         | Live calls to Helius, Firecrawl, Chainabuse (free tier, 10 calls a month, then reported unavailable), public blocklists |
| Evaluation                                  | 4 labelled scam addresses; independent recall 0 of 3 (see the README results). Small, and reported as such              |
| Mobile app                                  | Built and signed; not yet run on a device                                                                               |
| Test tokens in the devnet proofs            | Minted by `scripts/prove-devnet.ts`; no third-party token is involved                                                   |

## What we do not claim

- That HOLDBACK protects payments made outside it. A sender is protected only when paying through a hold.
- That the risk agent catches every scam. A brand-new wallet with no history is rated UNKNOWN; the 30-minute default window is what protects against it.
- That the window is insurance. A sender who never undoes is not protected.
- An audit, mainnet funds, or partners using it.
